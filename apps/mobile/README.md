# Ross Tax Pro Native Office

Production-oriented Expo application for iOS and Android using Clerk hosted authentication and secure native token storage.

## Registered identifiers

- iOS bundle ID: `com.rosstaxsoftware.virtualoffice`
- Android package: `com.rosstaxsoftware.virtualoffice`
- URL scheme: `rosstaxtpvo`
- Clerk Frontend API: `clerk.rosstaxsoftware.com`

## Required configuration

1. Enable Native API in the Clerk production instance.
2. Register both identifiers above. Apple registration additionally requires the Apple Team/App ID prefix.
3. Allow the native callback values generated by Clerk for the registered apps.
4. Set `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` in EAS secrets. A Clerk secret key must never be embedded.
5. Run `npm install`, `npm run doctor`, and `npm run typecheck`.
6. Use a development build; Clerk native capabilities are not supported in Expo Go.
7. Build with `eas build --platform ios --profile production` and `eas build --platform android --profile production` after Apple and Google signing credentials are approved.

Official implementation basis: Clerk Expo quickstart and hosted-auth documentation; Expo SDK 57.
