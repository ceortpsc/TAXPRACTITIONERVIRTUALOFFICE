# Ross Tax Pro Software Co. design system

## Brand posture

Precise, premium, accountable, human, and calm. Avoid government seals, implied IRS endorsement, novelty tax imagery, fake security badges, and decorative clutter.

## Palette

| Token | Value | Use |
|---|---|---|
| Navy 950 | `#040f20` | footer and maximum contrast |
| Navy 900 | `#071a32` | primary surfaces |
| Navy 700 | `#102a4a` | panels |
| Gold 500 | `#bc9650` | accents and focus |
| Cream 100 | `#f4eee3` | primary background |
| Paper | `#fffdf8` | content surfaces |
| Silver 300 | `#d6d9de` | dividers |
| Ink | `#152238` | body copy |

Typography pairs a high-contrast editorial display serif with a highly legible interface sans serif. Minimum contrast is WCAG AA. Focus indicators use gold plus a two-pixel offset. Motion respects `prefers-reduced-motion`.
