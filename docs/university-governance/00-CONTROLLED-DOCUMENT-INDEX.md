**Document class:** Institutional governance master set

**Control rule:** No document is official until its required approver, approval date, effective date, version, and superseded-document record are entered in the controlled repository.

## Academic affairs set

Academic catalog; school and department handbooks; curriculum committee charter and minutes; course and program approval forms; syllabus template; faculty credentialing standard; academic integrity, grading, standing, credit-hour and distance-learning policies; program and course outcomes; rubrics; academic calendar; online-course development standard; and faculty evaluation framework.

## Program and registrar set

Every program file contains overview, authority status, admissions, completion, plan of study, sequence, handbook, practicum, capstone, competencies, assessment plan, disclosure statement, and any applicable specialized-accreditation evidence. Registrar controls cover the SIS, education-record access, transcript design, corrections, holds, enrollment reporting, transfer credit, graduation audit, conferment, credential numbering, verification, retention, and disaster recovery.

## Required approval metadata

- Document code and title
- Version and effective date
- Draft owner and policy steward
- Legal review status
- Shared-governance consultation
- Executive or board approval
- Regulatory/accreditation evidence
- Publication location
- Review date and change history
- Superseded version and retention disposition
